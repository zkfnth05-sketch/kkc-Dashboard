# 🚨 Antigravity AI 필수 행동 지침 및 절대 수칙 (MANDATORY RULES)

모든 Antigravity AI 에이전트는 아래 4대 수칙을 최우선으로 준수해야 합니다.

1. **[신규 기능 개발 시 모듈 분리 원칙]**:
   - 기존 파일에 무리하게 코드를 덧붙이지 마십시오.
   - 반드시 별도 컴포넌트, 유틸리티, 서비스 파일 등으로 코드를 쪼개어(모듈화) 구현하십시오.

2. **[사전 원인 분석 및 선(先) 설명 의무]**:
   - 오류나 문제 발생 시 곧바로 코드를 수정하지 마십시오.
   - 근본 원인을 먼저 면밀히 파악하고, 사용자에게 "무엇이 왜 문제인지" 명확하게 설명부터 한 후, 사용자의 확인/승인을 받아 수정을 진행하십시오.

3. **[코드 전수 조사 및 신중한 답변 원칙]**:
   - 코드를 대충 훑거나 추측으로 섣부르게 대답하지 마십시오.
   - 관련된 코드 라인을 하나하나 정밀하게 뜯어보고 완벽히 검증한 후 답변하십시오.

4. **[무단/몰래 수정 및 깃 저장 절대 금지]**:
   - 대화 중이나 분석 중에 사용자의 명시적 지시 없이 은근슬쩍 코드를 몰래 수정하지 마십시오.
   - 사용자의 명시적 승인 없이 깃(Git) 커밋/푸시(`git commit`, `git push`)를 절대 실행하지 마십시오.
